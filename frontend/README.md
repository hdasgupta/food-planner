# Indian Food Planner — React + Capacitor Android

The same React/Vite frontend can run on the web and as a native Android app through Capacitor. The app uses the configured deployed API, so the backend must be reachable from the device.

## Web development

```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_API_URL` in `.env` to your deployed Express API URL ending in `/api` (for example, `https://your-api.example.com/api`). If unset, the frontend uses the production API URL defined in `src/api.js`.

## Generate the Android project

Requirements: Node.js 22+, Android Studio, Android SDK, and a compatible JDK (use the JDK version required by the Capacitor Android version installed).

From this `frontend` directory:

```bash
npm install
npm run cap:add       # Run only the first time; generates frontend/android/
npm run cap:sync      # Builds the web app and copies it into Android
npm run cap:open      # Opens the Android project in Android Studio
```

Then in Android Studio, allow Gradle sync to finish, select an emulator or connected Android device, and press **Run**. To create an APK, use **Build > Build Bundle(s) / APK(s) > Build APK(s)**.

For subsequent frontend changes, run `npm run cap:sync` before launching the Android app again. The `android/` folder is generated by Capacitor on the machine running `npm run cap:add`; do not manually create it or point `webDir` at the source folder. Capacitor serves the built `dist/` assets inside the app.

## API and network notes

- `capacitor.config.ts` sets the Android app ID to `org.wbfmh.indianfoodplanner` and app name to `Food Planner`.
- The backend API must use HTTPS for production Android builds and allow requests from the app origin through its CORS configuration.
- Do not put server secrets in `VITE_*` variables; Vite embeds these values in the client bundle.
